What This Product Does, Its Capabilities & Limitations (Future Scope)

Overview & Scope

What This Product Does

APEX-AP is an autonomous, enterprise-grade AI Accounts Payable and Vendor Procurement Automation Agent engineered as an intelligent top layer for higher-education institutional ERPs (such as JK Lakshmipat University, Jaipur). Sponsoring the Maker-Checker operational paradigm, the agent acts as an exhaustive, tireless Maker—ingesting vendor quotations and invoices in any format, evaluating technical and commercial trade-offs, checking market pricing, calculating taxes, verifying delivery receipts, enforcing statutory compliances, and drafting journal entries—while providing human institutional officers (Procurement Officers, Accounts Controllers, Deans, and the CFO) with tailored, high-context Checker views for final governance sign-offs.

Core Capabilities Delivered

1. Multi-Format Document Ingestion

Extracts structured data from PDF, Excel/CSV, Word (DOCX), PowerPoint (PPTX), Markdown, and scanned receipts via Google Gemini Multimodal Vision and deterministic regex fallback parsers.

2. Multi-Criteria Decision Analysis (MCDA)

Evaluates competing vendor proposals beyond lowest cost ($L_1$) through weighted scoring: Price 40%, Delivery Speed 20%, Warranty 20%, and After-Sales Service SLA 20%.

3. Live B2B Market Price Benchmarking

Automatically queries and benchmarks quoted item rates against Government e-Marketplace (GeM), Amazon Business, and IndiaMART in real time to prevent institutional price gouging.

4. 4-Tier Institutional Governance Workflow

Enforces university Delegation of Authority (DoA): HoD Requisition → Purchase Officer Scrutiny → Accounts Clearance → CFO Final Sanction before generating binding POs.

5. Line-by-Line 3-Way Reconciliation

Reconciles Invoices against Purchase Orders and Goods Receipt Notes (GRN). Flags price variances exceeding 2%, over-billing, unlisted items, and partial deliveries.

6. MSME Compliance & Balanced Double-Entry

Enforces Indian MSME 45-day statutory payment caps, captures early-payment cash discounts (e.g. 2% Net 10), and posts balanced General Ledger entries (`DR Expense`, `DR GST`, `CR AP`).

Current Limitations & Planned Future Scope

Capability Area Current Limitation (As of Now) Future Scope Roadmap
Direct Banking Gateway Execution Schedules payment vouchers and updates ERP ledger balances; does not execute live RTGS/NEFT wires. Direct integration with institutional corporate banking APIs (ICICI Corporate API, HDFC Enet, SBI CMP) with 2FA maker-checker token approvals.
Autonomous Vendor Communication Flags variances and alerts human Checkers; does not directly email or message vendors. Bidirectional autonomous communication agent (email and WhatsApp Business API) to solicit missing e-way bills, clarify delivery shortfalls, or request credit notes.
Adaptive OCR Template Self-Tuning Uses Gemini Vision + deterministic regex fallbacks; weights are static across all vendors. Few-shot adaptive learning pipeline that caches and optimizes extraction coordinates for recurring high-volume campus suppliers.
International & Foreign Currency Strictly handles Indian Rupee (INR) and Indian GST taxation (CGST, SGST, IGST). Multi-currency procurement engine (USD, EUR, GBP) supporting customs clearance documentation, forex spot rate hedging, and withholding tax (TDS under Sec 195).
Predictive Budget Burn Analytics Tracks static allocated vs actual vs committed budget envelopes. Time-series forecasting (ARIMA / Prophet) alerting Deans and HoDs 60 days in advance of projected fiscal year budget exhaustion.

Model Context Protocol (MCP) Server Specification

FastMCP Standard

What is the MCP Layer in APEX-AP?

The Model Context Protocol (MCP) is an open protocol that standardizes how AI applications connect with external databases, business logic, and enterprise context. In APEX-AP, the FastMCP Server (ap_agent/erp_mcp_server.py) sits cleanly between the autonomous Gemini Agent Maker and the underlying SQLite/Postgres ERP database. The agent never executes raw SQL statements; instead, it discovers and calls verified, audited MCP tools through standardized JSON-RPC schemas.

Declared ERP MCP Tools
Tool Name Input Schema Functionality & Return Object
erp_lookup_vendor { "vendor_name": str } Performs fuzzy match against ERP Vendor Master. Returns vendor ID, PAN/GSTIN, MSME registration status, and payment terms.
erp_lookup_po { "po_number": str } Queries ERP Purchase Order table. Returns PO status, line items, approved quantities, unit prices, and department code.
erp_get_grns { "po_number": str } Retrieves warehouse Goods Receipt Notes (GRN) for the specified PO. Returns inspected and accepted delivery quantities.
erp_check_budget { "department": str, "amount": float } Validates if requisition amount is within allocated department budget. Returns available balance and over-limit alert flags.
erp_post_invoice_liability { "invoice_id": str, "subtotal": float, "tax": float, "total": float } Posts balanced double-entry journal vouchers to the ERP General Ledger (`DR Expense`, `DR GST`, `CR Accounts Payable`).
erp_record_payment { "invoice_id": str, "amount": float, "discount_taken": float } Disburses settlement payment in the ERP ledger, clearing the AP liability and recognizing early payment cash discounts.
erp_get_department_budget { "department": str } Returns comprehensive department budget envelope: allocated budget, actual spend, encumbered commitments, and uncommitted balance.

    }
  }
